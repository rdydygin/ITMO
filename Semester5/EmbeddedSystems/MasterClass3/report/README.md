# Отчет по мастер-классу 3

Отчет_МК3_Вариант1.docx — редактируемый отчет. Отчет_МК3_Вариант1.pdf — версия для сдачи. Оформление, титульный лист и структура взяты из отчета МК2: 9 страниц; Тимошкин Роман Вячеславович и Муравенко Григорий Павлович, P3330; преподаватель Быковский Сергей Вячеславович.

Кадры OLED получены из snake.c, oled.c, fonts.c и функции отрисовки текущего проекта. Для сценария роста еда поставлена перед головой. Модель сохраняет байты кадрового буфера через подмену HAL_I2C_Mem_Write и не моделирует электрические сигналы или планировщик RTOS. Подтверждение работы управления на стенде получено в ходе проверки пользователем.

Из корня MasterClass3:

```sh
clang -std=c11 -Wall -Wextra -Werror -Ireport/simulator -ISDK_Snake/Core/Inc \
  report/simulator/model.c SDK_Snake/Core/Src/snake.c \
  SDK_Snake/Core/Src/oled.c SDK_Snake/Core/Src/fonts.c -o /tmp/mc3-oled-model
/tmp/mc3-oled-model
```

build_report.py заменяет содержание в копии Word-отчета МК2, сохраняя его стили, поля, структуру таблиц и титульный лист. Создает диаграммы и оформленные изображения экрана; использует python-docx-compatible OOXML, lxml и Pillow. Исходный отчет МК2 не изменяется. package_verification.json содержит проверку сохранения остальных частей пакета DOCX.
