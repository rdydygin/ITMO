# Вариант 1 — калькулятор

Программа для SDK1.1M: сложение, вычитание и умножение целых чисел с вводом на клавиатуре и выводом на OLED. Диапазон значений: от -2147483648 до 2147483647. Переполнение отображается как OVERFLOW.

Кнопки сверху вниз, слева направо: `1 2 3`, `4 5 6`, `7 8 9`, `* 0 #`.

1. Введите первое число.
2. Нажмите `*`: выбирается сложение. До ввода второго числа повторное нажатие `*` переключает операции: `+`, `-`, `*`, снова `+`.
3. Введите второе число.
4. Нажмите `#` для вычисления.

Удержание `*` 0,7 секунды очищает всё. Удержание `#` 0,7 секунды меняет знак вводимого числа; можно использовать до набора цифр. Короткие нажатия обрабатываются после отпускания. После результата цифра начинает новый пример, а `*` позволяет использовать результат как первое число следующего примера.

Примеры:

- `12`, `*`, `34`, `#` → 46.
- `12`, `*`, `*`, `34`, `#` → -22.
- `12`, `*`, `*`, `*`, `34`, `#` → 408.

Реализация: `Inc/calculator.h` — арифметика и состояние; `Src/main.c` — опрос, подавление дребезга 30 мс, удержание и дисплей; `Src/kb.c` — сканирование матрицы. Ошибки I2C и неоднозначные нажатия не принимаются за цифры.

## Сборка и загрузка без IDE

```sh
./lab.sh build   # собрать
./lab.sh flash   # собрать, прошить, проверить запись и запустить
./lab.sh clean   # очистить результаты сборки
```

Открывайте в VS Code каталог MasterClass2: Cmd+Shift+B — сборка; Terminal → Run Task → «Собрать и прошить» — загрузка. Расширения для этих задач не нужны.

Подключите плату и завершите другую активную отладку перед flash. Прошивка выполняется через FTDI/JTAG с SDK11M.cfg. Результаты сборки находятся в build/SDK_Keyboard.elf, .hex и .bin. Изменения исходников и заголовков учитываются автоматически.

Скрипт ищет ARM GNU Toolchain, make и OpenOCD в PATH, затем среди инструментов установленной STM32CubeIDE на macOS. Запускать IDE не требуется. Можно использовать отдельно установленные инструменты, добавив их в PATH. Дополнительные настройки: OPENOCD_BIN — путь к OpenOCD; OPENOCD_SCRIPTS — каталог с target/stm32f4x.cfg; CUBEIDE_PLUGINS — каталог плагинов IDE; JOBS — число потоков сборки (по умолчанию 4).

Отладка: ./lab.sh debug запускает сервер и останавливает процессор; во втором терминале ./lab.sh gdb подключает GDB. Команды GDB: break main, monitor reset halt, continue, next, print. Ctrl+C останавливает выполнение; detach и quit завершают сессию. Сервер останавливается Ctrl+C в первом терминале.


Проверки логики: `clang -std=c11 -Wall -Wextra -Werror -fsanitize=undefined,address -IInc tests/calculator_test.c -o /tmp/calculator_test && /tmp/calculator_test`.
