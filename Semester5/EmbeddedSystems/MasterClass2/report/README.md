# Отчет по мастер-классу 2

Отчет_МК2_Вариант1.docx — редактируемый отчет, 9 страниц. Исполнители: Тимошкин Роман Вячеславович и Муравенко Григорий Павлович, P3330.

sequence_init.puml и sequence_loop.puml — описания диаграмм последовательностей. Изображения схем и кадров OLED находятся в assets.

Иллюстрации OLED получены программной моделью с арифметикой, шрифтами и драйвером отрисовки из проекта. Функция Calculator_Display извлечена из Src/main.c; HAL_I2C_Mem_Write захватывает байты кадрового буфера. Физические сигналы и временные характеристики стенда не моделируются.

Запуск модели из каталога report:

```sh
clang -std=c11 -Wall -Wextra -Werror -Isimulator -I../Inc simulator/model.c ../Src/oled.c ../Src/fonts.c -o /tmp/sdk-calculator-model
/tmp/sdk-calculator-model '12*34#' /tmp/add.pgm
```

Символ N в аргументе модели означает смену знака, C — очистку. Цифры, * и # передаются в обработчик калькулятора. model_results.txt содержит результаты восьми сценариев.

build_report.py повторно создает DOCX из сохраненных материалов; требуются python-docx и Pillow. При изменении программы модель следует обновить и повторить проверки.

Отчет_МК2_Вариант1.pdf — готовая версия для сдачи.
