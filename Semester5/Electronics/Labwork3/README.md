# ЛР3. Исследование полупроводникового диода

Вариант 354, диод UMN11N (ROHM). Отчёт: `ЛР3_Тимошкин_P3330_354.pdf`.

- `assets/` — скриншоты LTspice (схемы, ВАХ, осциллограммы выпрямителя, закрывание диода) и даташит диода.
- `report/calc.py` — расчёт по SPICE-модели UMN11N из `standard.dio`: контрольные точки ВАХ, порог и сопротивления при Io = 100 мА с точностью до тысячных.
- `report/report.typ` — исходник отчёта.

```bash
cd report
python3 -I calc.py
typst compile --root .. report.typ "../ЛР3_Тимошкин_P3330_354.pdf"
```
