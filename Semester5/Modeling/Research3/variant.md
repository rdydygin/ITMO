# Исходные варианты

Часть 1: СИСТЕМА_1, выбранная в УИР2, вариант **32/32/30**.

- Два прибора, общая очередь FIFO на 7 мест (всего в системе 9 мест).
- Проверка УИР2: пуассоновский поток λ=0,5 с⁻¹, экспоненциальное обслуживание b=10 с.
- При двух свободных приборах выбор П1/П2: 0,65/0,35.
- Основные эксперименты: средний межприходный интервал из 300 значений УИР1,
  a=11,995543333333334 с; коэффициент вариации 2,3336078058699954.
- Аппроксимация УИР1: H2 с p=0,9152459652638409,
  средними ветвей 6,553180122392202 и 70,76679812752096 с.
