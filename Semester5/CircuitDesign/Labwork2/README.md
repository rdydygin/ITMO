# Лабораторная работа № 2. Многотактная реализация цифрового блока

Вариант 2 из [задания v2](../docs/Функциональная_схемотехника_Labs_tasks_v2.pdf)
вычисляет `y = a³ + ⌊√b⌋`. Оба входа беззнаковые 16-разрядные.
Выход `y` имеет 48 бит. Верхний автомат дважды запускает один
последовательный умножитель и параллельно вычисляет квадратный корень.

[Отчёт в PDF](report/ЛР2_Тимошкин_РВ.pdf) содержит графы переходов,
описание алгоритма, область значений и временные диаграммы.

## Интерфейс блока

Модуль [function_multicycle](rtl/function_multicycle.v) принимает `a` и `b`
по положительному фронту `clk` при `start = 1` и `busy = 0`. Через 38
периодов тактирования обновляется выход `y`, `busy` сбрасывается, а `done`
выдаёт импульс длиной в один такт. Задержка при 100 МГц составляет 380 нс.
Запросы во время `busy` игнорируются. `rst` асинхронно прерывает
вычисление и обнуляет `y`, `busy` и `done`.

Каждый арифметический модуль имеет свой автомат и интерфейс `start`/`done`.

| Модуль | Операция | Задержка |
| --- | --- | --- |
| [`mul_multicycle`](rtl/mul_multicycle.v) | Умножение в столбик, 32 × 16 → 48 бит | 16 тактов |
| [`sqrt_multicycle`](rtl/sqrt_multicycle.v) | Целый квадратный корень, 16 → 8 бит | 8 тактов |
| [`add_multicycle`](rtl/add_multicycle.v) | Сложение по 16-битным словам, 48 + 8 → 49 бит | 3 такта |

## Симуляция и отчёт

Из каталога `Labwork2`:

```sh
make test     # ядро, отдельные арифметические модули и интерфейс платы
make figures  # обновляет SVG из build/function.vcd, требуется Python 3
make report   # собирает PDF из report/main.typ, требуется Typst
```

Тест ядра сравнивает с эталоном 531 пару аргументов. Отдельный тест
проверяет все 65 536 входов блока корня, полное произведение и перенос
в старший бит сумматора. Модель платы проверяет успех самотеста,
сигнал ошибки при подмене результата и перезапуск по сбросу.

## Самотест на Saylinx с Mac

Подключите USB-Blaster к разъёму JTAG по
[инструкции к Saylinx](../fec_saylinx_project_example/README.md). Из каталога
`Labwork2` загрузите готовый файл в SRAM платы:

```sh
brew install openfpgaloader
openFPGALoader -c usb-blaster --detect
openFPGALoader -c usb-blaster --write-sram quartus/output_files/lab2.rbf
```

Самотест запускается после захвата PLL. Автомат подаёт две пары
и сравнивает результаты после `done`.

| `a` | `b` | Ожидаемый результат |
| --- | --- | --- |
| `0003` | `000F` | `00000000001E` |
| `FFFF` | `FFFF` | `FFFD000300FE` |

Если совпали оба результата, горит **LED0**. При расхождении загорается
**LED1**. Во время сброса и проверки оба погашены. Нажатие и отпускание
K1 запускает тест заново. Физическая проверка требует подключения Saylinx.
