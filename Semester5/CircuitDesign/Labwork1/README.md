# Лабораторная работа 1 — Введение в Verilog HDL

**Вариант 2 — демультиплексор 1 в 2** (в методичке опечатка: «2 в 1»).
Вход данных `d`, адресный вход `sel`, выходы
`y0 = d & ~sel` и `y1 = d & sel`. Модули реализованы, симуляция проходит, отчёт собран.

## Варианты из методички

| Вариант | БОЭ |
| --- | --- |
| 1 | Мультиплексор 2 в 1 |
| 2 | Демультиплексор 1 в 2 (в методичке опечатка: «2 в 1») |
| 3 | Шифратор 2 в 1 |
| 4 | Дешифратор 1 в 2 |
| 5 | Двоичный полный компаратор |
| 6 | Двоичный полный сумматор |
| 7 | Двоичный полный вычитатель |

## Файлы

| Файл | Назначение |
| --- | --- |
| `rtl/boe_assign.v` | Демультиплексор 1 в 2 только на `assign` |
| `rtl/boe_always.v` | Тот же элемент на `always @*` |
| `rtl/boe_param.v` | `WIDTH`-разрядный демультиплексор из `boe_assign` через `generate` |
| `rtl/result_register.v` | Регистр с асинхронным сбросом, активным высоким уровнем |
| `rtl/boe_registered.v` | `boe_param` + регистр шириной `2*WIDTH`, `result = {y1, y0}` |
| `tb/tb_result_register.v` | Самопроверяющийся тест регистра |
| `tb/tb_boe.v` | Самопроверяющийся тест БОЭ, параметризуемого модуля и составного устройства |
| `report/main.typ` | Исходник отчёта |
| `report/vcd_wave.py` | Построение SVG временных диаграмм из VCD (только стандартная библиотека Python) |
| `report/figures/` | Схемы (нарисованы вручную) и временные диаграммы (генерируются) |

## Симуляция

Нужны Icarus Verilog (`iverilog`, `vvp`) и `make`. Из папки `Labwork1`:

```sh
make test-register
```

При успешной проверке выводится `PASS: result_register`, временная диаграмма
сохраняется в `build/result_register.vcd` (открывается, например, в GTKWave).

```sh
make test
```

Полная проверка: регистр и `tb_boe` (538 проверок: таблица истинности обеих
реализаций, `WIDTH=1`, крайние векторы и полный перебор при `WIDTH=8` против
независимой модели, сброс/запись/хранение составного устройства). Ожидаемый вывод —
`PASS: boe (538 checks)`, диаграмма сохраняется в `build/boe.vcd`.

## Отчёт

```sh
make figures   # моделирование и временные диаграммы report/figures/wave_*.svg
make report    # report/report.pdf
```

Нужны Typst CLI и Python 3. Настройки Typst локальные (A4, поля не менее 20 мм,
текст 14 pt, титульный лист без номера), сетевые пакеты не используются.
